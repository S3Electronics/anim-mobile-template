# ทำคลิป animation จากมือถือ ด้วย GitHub + Claude Code

repo ต้นแบบ: Fork ไปแล้วสั่ง Claude เขียนคลิปได้ทันที ไม่ต้องมีคอม

ดูคลิปตัวอย่าง (กดเล่น / กดบันทึกเป็น MP4 ได้): https://s3electronics.github.io/anim-mobile-template/

สไลด์สอนทีละขั้น: https://hub.juicystock.com/hub/motion/mobile-anim/

★คนใหม่ เริ่มที่นี่: [START-TH.md](START-TH.md) — บัญชีที่ต้องมี, เชื่อม Claude กับ GitHub, ตั้งเสียงพากย์, เช็กว่าใช้ได้

## เริ่มใช้ 5 ขั้น

1. กดปุ่ม Fork (มุมขวาบนของหน้านี้) → Create fork  ได้ repo ชื่อ `anim-mobile-template` ในบัญชีเรา
2. ไปที่ repo ของเรา → Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
3. รอ 1-2 นาที เปิด `https://ชื่อบัญชี.github.io/anim-mobile-template/` จะเห็นคลิปแมว
4. เปิดแอป Claude → แท็บ Code → เลือก repo `anim-mobile-template` → พิมพ์สั่งงาน (ตัวอย่างข้างล่าง)
5. Claude เปิด Pull Request ให้ → กด Create PR / Merge → รอ 1-2 นาที → เปิดลิงก์เดิม → กด "⬇ บันทึกเป็น MP4"
   - iPhone: แตะลิงก์ "แตะเพื่อบันทึก" → แชร์ → บันทึกวิดีโอ
   - Android: ไฟล์อยู่ในโฟลเดอร์ Download

## คำสั่งตัวอย่าง (ก๊อปไปวางในแท็บ Code)

1) stick man เล่าเรื่อง
```
เปลี่ยนคลิปใน index.html เป็นเรื่องใหม่ ยาว 50 วินาที สไตล์ stick man
เรื่อง: หนุ่มออฟฟิศตื่นสาย วิ่งไปขึ้นรถเมล์ แต่สุดท้ายวันนี้วันอาทิตย์
แบ่ง 4 ฉาก มีซับไทยตัวใหญ่ทุกฉาก ฉากสุดท้ายหักมุมให้ขำ
```

2) motion graphic ตัวหนังสือ + ไอคอน
```
สร้างคลิปใหม่ในโฟลเดอร์ tips/index.html ยาว 45 วินาที สไตล์ motion graphic พื้นดำ
หัวข้อ "5 วิธีประหยัดเงินเดือน" ตัวหนังสือเด้งเข้าทีละคำ มีไอคอนวาดเองข้อละ 1 อัน
ใช้ปุ่มเล่น/บันทึก MP4 แบบเดียวกับ index.html
```

3) สั่งแก้ทีละจุด
```
แก้แค่จุดเดียว: วินาทีที่ 12-15 ซับเล็กไปอ่านไม่ทัน ขยายเป็น 80px และค้างไว้นานขึ้น 1 วินาที
ส่วนอื่นห้ามเปลี่ยน
```

## เสียง: เพลง + เสียงประกอบ + เสียงพากย์ AI

คลิปตัวอย่างมีครบ 3 อย่าง ตรงจังหวะภาพ และติดไปในไฟล์ MP4 ด้วย

- เพลง/เสียงประกอบ: มีคลังเสียงฟรี CC0 ใน `sounds/` 39 ไฟล์ (ซอมบี้ กรีดร้อง หัวใจเต้น ประตู ฟ้าร้อง วูบ ระเบิด แมว หมา ... + เพลง 7 อารมณ์) + คลังเสริม ~340 ไฟล์ที่ [anim-sounds](https://github.com/S3Electronics/anim-sounds) + เสียงสังเคราะห์ `synth:*` ที่ไม่ต้องมีไฟล์
- เสียงพากย์ AI: พิมพ์ข้อความในคลิป → มือถือสร้างเสียงให้ด้วย Gemini (ฟรี) → กดปุ่ม 🔑 ใส่คีย์ครั้งเดียว สร้างคีย์ที่ https://aistudio.google.com/apikey (คีย์เก็บในมือถือ ไม่ขึ้น GitHub)
- ซับในคลิปมาจากข้อความเสียงพากย์ จึงตรงกับเสียงเสมอ

สั่ง Claude ได้เลย เช่น
```
ใส่เสียงซอมบี้คำรามตอนวินาทีที่ 5 ที่ซอมบี้โผล่ เพลงพื้นหลังแนวสยอง
และเสียงพากย์ผู้ชายเล่าเรื่องทุกฉาก
```
Claude จะหาเสียงจากคลังเอง (`node tools/find-sound.mjs ซอมบี้`) ถ้าไม่มีจะโหลดจากคลังเสริมมาใส่ให้

## ในนี้มีอะไร
- `index.html` คลิปตัวอย่าง "แมวหายตอนเที่ยงคืน" 20 วินาที (ภาพ + ตั้งค่าเสียง) ← ไฟล์ที่สั่งแก้
- `player.js` ปุ่มเล่น / บันทึก MP4 พร้อมเสียง (ทำในเครื่อง ไม่ต้องมีเซิร์ฟเวอร์) / ปุ่มคีย์เสียงพากย์
- `sound.js` ระบบผสมเพลง + เสียงประกอบ + เสียงพากย์ AI ให้ตรงเวลา
- `sounds/` คลังเสียง CC0 + `catalog.json` (ชื่อ แท็ก ผู้สร้าง ลิงก์ต้นทาง) · `voice/` เสียงพากย์ของคลิปตัวอย่าง
- `tools/find-sound.mjs` ค้นหา/โหลดเสียงฟรีเพิ่ม
- `CLAUDE.md` กติกาที่ Claude อ่านอัตโนมัติ: 9:16, ปุ่ม MP4, วิธีใส่เสียงให้ตรงจังหวะ, วิธีหาเสียงเอง

เสียงทั้งหมดใน `sounds/` เป็น CC0 จาก Freesound (ผ่าน Openverse) ใช้ได้ทุกงานรวมถึงเชิงพาณิชย์ ไม่ต้องให้เครดิต (รายชื่อผู้สร้างอยู่ใน catalog.json)
