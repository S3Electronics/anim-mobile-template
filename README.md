# ทำคลิป animation จากมือถือ ด้วย GitHub + Claude Code

repo ต้นแบบ: Fork ไปแล้วสั่ง Claude เขียนคลิปได้ทันที ไม่ต้องมีคอม

ดูคลิปตัวอย่าง (กดเล่น / กดบันทึกเป็น MP4 ได้): https://s3electronics.github.io/anim-mobile-template/

สไลด์สอนทีละขั้น: https://hub.juicystock.com/hub/motion/mobile-anim/

## เริ่มใช้ 5 ขั้น

1. กดปุ่ม Fork (มุมขวาบนของหน้านี้) → Create fork  ได้ repo ชื่อ `anim-mobile-template` ในบัญชีเรา
2. ไปที่ repo ของเรา → Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
3. รอ 1-2 นาที เปิด `https://ชื่อบัญชี.github.io/anim-mobile-template/` จะเห็นคลิปแมว
4. เปิดแอป Claude → แท็บ Code → เลือก repo `anim-mobile-template` → พิมพ์สั่งงาน (ตัวอย่างข้างล่าง)
5. Claude เปิด Pull Request ให้ → กด Create PR / Merge → รอ 1-2 นาที → เปิดลิงก์เดิม → กด "⬇ บันทึกเป็น MP4"
   - iPhone: แตะลิงก์ "แตะเพื่อบันทึก" → แชร์ → บันทึกวิดีโอ
   - Android: ไฟล์อยู่ในโฟลเดอร์ Download

## คำสั่งตัวอย่าง (ก๊อปไปวางในแท็บ Code)

1) stick man เล่าเรื่อง
```
เปลี่ยนคลิปใน index.html เป็นเรื่องใหม่ ยาว 50 วินาที สไตล์ stick man
เรื่อง: หนุ่มออฟฟิศตื่นสาย วิ่งไปขึ้นรถเมล์ แต่สุดท้ายวันนี้วันอาทิตย์
แบ่ง 4 ฉาก มีซับไทยตัวใหญ่ทุกฉาก ฉากสุดท้ายหักมุมให้ขำ
```

2) motion graphic ตัวหนังสือ + ไอคอน
```
สร้างคลิปใหม่ในโฟลเดอร์ tips/index.html ยาว 45 วินาที สไตล์ motion graphic พื้นดำ
หัวข้อ "5 วิธีประหยัดเงินเดือน" ตัวหนังสือเด้งเข้าทีละคำ มีไอคอนวาดเองข้อละ 1 อัน
ใช้ปุ่มเล่น/บันทึก MP4 แบบเดียวกับ index.html
```

3) สั่งแก้ทีละจุด
```
แก้แค่จุดเดียว: วินาทีที่ 12-15 ซับเล็กไปอ่านไม่ทัน ขยายเป็น 80px และค้างไว้นานขึ้น 1 วินาที
ส่วนอื่นห้ามเปลี่ยน
```

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เปิดลิงก์แล้ว 404 | ยังไม่เปิด Pages (ขั้น 2) หรือรอไม่ถึง 2 นาที / ลิงก์ต้องเป็นตัวพิมพ์เล็ก |
| Merge แล้วลิงก์ยังเป็นคลิปเก่า | รอ 1-2 นาที แล้วดึงหน้าจอลงรีเฟรช หรือเติม `?1` ท้ายลิงก์ |
| แท็บ Code หา repo ไม่เจอ | ยังไม่ให้สิทธิ์ Claude GitHub App กับ repo นี้ → ตั้งค่า GitHub ในแอป Claude เลือก repo เพิ่ม |
| กดบันทึก MP4 แล้วนาน | เครื่องเก่าจะอัดแบบเรียลไทม์ ต้องรอเท่าความยาวคลิป อย่าสลับแอป |
| ได้ไฟล์ .webm (Android บางรุ่น) | ใช้ Chrome รุ่นใหม่ หรือเปิดใน CapCut แล้ว export เป็น MP4 |
| ตัวหนังสือไทยเพี้ยน/สระลอย | สั่ง "ใช้ฟอนต์ Kanit และรอฟอนต์โหลดก่อนวาด" |
| Claude แก้เกินที่สั่ง | ใส่คำว่า "แก้แค่จุดเดียว ส่วนอื่นห้ามเปลี่ยน" + บอกวินาที |
| ไม่มีเสียง | ตั้งใจไม่ใส่ ไปใส่เพลง/พากย์ใน TikTok หรือ CapCut |
